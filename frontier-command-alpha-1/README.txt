Frontier Command Alpha 1.0 — opening campaign prototype
Upload index.html, campaign.js, personnel.js and llm.worker.js together into a NEW GitHub Pages folder. Do not overwrite v0.7. CAMPAIGN-DESIGN.md contains spoilers; keep it offline if desired.
Start with Hiroki's message. Contact Arin Vale and type: Investigate the signal at Nacre Reach. Watch Stellar Cartography and live tasks for 32 seconds. Then type: Recover the survivors. Contact Hiroki and type: Analyze the signal. Contact Vale and type: Investigate the relay. Mining captains can be contacted through Personnel; type: Mine the belt. Return to the Lighthouse is supported. State autosaves locally and simulated time stops when the page is closed. Optional local WebLLM requires HTTPS/WebGPU.
Limitations: bounded phrase-based order parser; recovery and science followups currently immediate; no full alien diplomacy, combat, moral unlocks or later acts; v0.14 3D station not integrated. Browser and WebLLM end-to-end testing outstanding.
