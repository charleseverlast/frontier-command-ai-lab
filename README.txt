FRONTIER COMMAND — AI COMMUNICATIONS LABORATORY

Standalone browser experiment. It does not modify the main game or its saved data.

HOW TO TEST (NO PAID HOSTING):
1. Extract the ZIP package to a folder containing index.html and llm.worker.js.
2. Host BOTH files together on a secure (HTTPS) static site (for example, Netlify Drop or GitHub Pages).
3. Open the HTTPS website in Safari on a WebGPU-compatible iPad or in Chrome/Edge on a compatible computer.
4. Try fallback dialogue immediately. Press "Load local AI" to download/init the 1B model.
5. Ask Arin to open hailing frequencies, decode the signal, deploy a probe, etc.

IMPORTANT: Double-clicking index.html on a computer uses file:// and may break module workers. Host over HTTPS.
WebLLM is free to use locally, but an initial model download and WebGPU support are required.
No microphone is integrated in this lab; it has suggested replies and free typing.
The AI generates dialogue only. Scripted simulation state controls verified outcomes.
JavaScript module API is based on https://webllm.mlc.ai/docs/user/get_started.html
